# E-commerce Sales Analysis using MySQL

## Project Overview

This project analyzes e-commerce sales data using MySQL. The dataset was prepared and structured into separate customer and order tables before analysis.

## Dataset

* Source: Kaggle
* Orders: 10,000
* Unique Customers: 4,327

## What I Did

* Prepared and cleaned the dataset before importing it into MySQL.
* Separated customer and order data into relational tables.
* Removed duplicate customer records.
* Defined appropriate data types and primary/foreign key constraints.
* Wrote SQL queries to answer business-related questions.
* Used aggregations, JOINs, subqueries, CTEs, window functions, views, and stored procedures.

## Project Structure

* `schema/` – Table creation scripts
* `data/` – Dataset source information
* `queries/` – Beginner, intermediate, and advanced SQL queries
* `screenshots/` – Query results and database screenshots
